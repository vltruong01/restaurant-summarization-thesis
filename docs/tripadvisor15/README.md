# TripAdvisor15 public photo viewer

Open `index.html` offline, or serve this directory from GitHub Pages. The public gallery includes all 73 exact selected photographs, original/filtered BLIP-2 captions, photo IDs, publisher references and enlargement. Image bytes and native dimensions match the frozen inference evidence.

Original review bodies, generated summary passages and individual evaluator records remain excluded. Published aggregate/per-restaurant scores and output digests are unchanged. No build, server dependency or external image hotlink is required.
