# TripAdvisor15 complete research viewer

Open `index.html` offline or through GitHub Pages. All 15 restaurants have the original selected reviews, 73 selected photo files, exact BLIP-2 captions, all three original Review Consensus and Visual Evidence outputs, and original pseudonymous A01/A02 scores.

All source texts, image bytes, model outputs, score values and verified numerical results are preserved. Original output errors and repetition are retained. Qwen-Image shares Qwen-Caption's Review Consensus. No overall winner is selected automatically.

No evaluator real identities, credentials, comments, session records or submission timestamps are included. No new inference or evaluation is required. The complete public edition was requested by the researcher.
